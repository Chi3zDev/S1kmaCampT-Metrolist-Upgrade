# Experimental general video search (Android debug only)

This branch is an experiment, not a release. Home exposes its entry only in Android debug builds. Search uses the existing InnerTube session with the WEB client, rather than YouTube Data API. It parses the first page of video and channel results and sends chosen videos to the existing music video player. The live filter and live badge depend on YouTube's unofficial response format. Channels currently open in YouTube; browsing channel uploads inside the app is not implemented. Playback needs music video playback enabled and may fail for restricted content, live streams, or non-music videos. YouTube may change or restrict the endpoint at any time. This is not an official YouTube embedded player, and existing background behavior is not evidence of YouTube API policy compliance; review service terms before any release.

Before making an APK available, compile and run the parser tests. On a device verify ordinary videos, live streams, channel searches, no-results/offline/retry, rotation and Back, disabling video playback, player errors, concurrent music playback, accessibility, light/dark and glass themes. Check small screens, navigation insets, and playback behavior when leaving the page. Search pagination, in-app channel pages, and unrestricted playback are not implemented. Debug has application ID suffix `.debug` and is a separate install; it does not upgrade or carry the data of the release app.
