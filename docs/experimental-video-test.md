# General video search (release candidate work in progress)

This branch is not yet a release. The Home entry is available in Android builds of this branch. Search uses the existing InnerTube session with the WEB client, rather than YouTube Data API. It parses the first page of video and channel results and sends chosen videos to the existing music video player. The live filter and live badge depend on YouTube's unofficial response format. Channels currently open in YouTube; browsing channel uploads inside the app is not implemented. Playback needs music video playback enabled and may fail for restricted content, live streams, or non-music videos. YouTube may change or restrict the endpoint at any time. This is not an official YouTube embedded player, and existing background behavior is not evidence of YouTube API policy compliance; review service terms before any release.

Before releasing, compile and run the parser tests. Local video sessions are marked in the serialized queue and excluded from local history writes, live Streak progress and the first-play Streak celebration. Verify that the flag survives resolution, restart, queue transitions and the same video ID played as music, and that remote YouTube history synchronization cannot reintroduce a video session into Recap or Streak; remote-sync exclusion is not yet established. On a device verify ordinary videos, live streams, channel searches, no-results/offline/retry, rotation and Back, disabling video playback, player errors, concurrent music playback, accessibility, light/dark and glass themes. Check small screens, navigation insets, and playback behavior when leaving the page. Search pagination, in-app channel pages, and unrestricted playback are not implemented. Debug has application ID suffix `.debug` and is a separate install; it does not upgrade or carry the data of the release app.
